🔍 Fact Checker AI – settings

This extension assesses the credibility of AI chat answers (ChatGPT, Gemini, Claude) and of web pages / news, auto-detects the content language, and suggests critical verification questions in that language. For content-tailored questions you need your own API key.

Model provider

Checking on-device model availability…

The model runs in your browser – no data leaves the device. On first use Chrome downloads the model once (several GB, needs an unmetered connection). Requires Chrome 138+ and capable hardware; if unsupported, the extension falls back to general questions. Note: the on-device model works best in English; other languages may be lower quality.

Cloud server (recommended)

When set, Fact Checker runs on your cloud server (your API key stays on the server) and uses Google Search grounding — it verifies claims against real web sources and shows them under the result. My Career / Linglerno also use this server. Leave empty to run locally (on-device / your own key), without web verification.

API access (optional – only without a server)

Behavior

Sets the language of the panel labels AND of the model's answers (summary, questions, My Career / Linglerno) — regardless of the language of the page you analyze.

Profile & progress

Your profile — career details, languages and level — lives in the Library, together with everything it feeds: vocabulary with spaced-repetition reviews, a competence map built from what you read, XP and a streak. Kept locally in this browser: no account, no server, nothing leaves the device.

Your API key is stored locally in the browser (chrome.storage.sync) and sent only to the selected provider.
