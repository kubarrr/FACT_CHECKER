🔍 Fact Checker AI – settings

This extension assesses the credibility of AI chat answers (ChatGPT, Gemini, Claude) and of web pages / news, auto-detects the content language, and suggests critical verification questions in that language. For content-tailored questions you need your own API key.

Model provider

Checking on-device model availability…

The model runs in your browser – no data leaves the device. On first use Chrome downloads the model once (several GB, needs an unmetered connection). Requires Chrome 138+ and capable hardware; if unsupported, the extension falls back to general questions. Note: the on-device model works best in English; other languages may be lower quality.

API access

Behavior

Your API key is stored locally in the browser (chrome.storage.sync) and sent only to the selected provider.
